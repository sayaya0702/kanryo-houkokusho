# 完了報告書 作成ツール

工事・作業完了報告書をスマホ／PCで作成し、PDFとして保存できる単一ページのWebアプリです。

- **形式A**：ビフォーアフター（左:工事前／右:工事後、表紙＋3組/ページ）
- **形式B**：写真＋コメント（写真1枚＋No.＋見出し＋コメント欄、3枚/ページ）
- 写真は端末内だけで処理され、サーバーへ送信・保存されません。
- PWA対応（ホーム画面に追加／オフライン利用可）。

## 使い方
ブラウザで `index.html`（またはデプロイ先URL）を開く → 形式を選ぶ → 情報と写真を入れる → 「PDFを保存」。

## 配信
静的ファイルのみ。GitHub Pages / Vercel / Firebase Hosting などにそのまま配置できます。
